# 지정 회차 자동발행 준비 상태 · 2026-10-21

## 현재 요청

생활경제·리빙 전환 구상은 `living-news-future-concept.md`에 보관하고 시행을 보류한다. 기존 편집 범위·브랜드·검증 원칙을 유지한다.

오늘 한국시간16:00·16:30·17:00·17:30만 발행 대상 회차로 설정했다. 시작 후10분을 지연 허용 범위로 두고, 그 이후에는 소급 게시하지 않는다. 발행 관문은 발행 직전에도 절대 날짜·시각과 회차 사용 이력을 확인한다. 다음 날과 다음 해에는 동일 시각에도 게시할 수 없다. 기존10분 수집 실행 일정은 유지하며 매 실행에서 무조건 게시하지 않는다. 서버 예약 지연으로 회차를 놓칠 수 있다.

이는 **허용 시간 제어 구현**이며 예약 게시 완료나 자동 운영 개시 선언이 아니다.

## 남아 있는 필수 연결

- 현재 대화의 로컬 실행 환경에서는 Claude API 키와 공식 Instagram 게시 인증 환경변수가 설정되지 않았다. GitHub Secrets의 존재 여부는 여기서 확인하지 않았으므로 원격 키가 없다고 단정하지 않는다.
- Claude 조사·구조화 원고·별도 근거 검수 어댑터는 미연결이다. 잔액 약450달러는 사용자 진술이며 실제 조직·만료·가격·잔액·청구는 확인하지 않았다. API 호출·크레딧 사용·추가 결제를 하지 않았다.
- 자동 파이프라인의 독립 내용 검증기도 여전히 미연결이다. 형식 검증 테스트 성공은 사실 확인 완료가 아니다.
- 공식 게시 인증·계정 할당량 조회가 준비되지 않았다. 수동 게시 성공을 실행기의 무인 게시 연결로 취급하지 않는다.
- 기존 운영 상한3건은 플랫폼 최대량이 아니다. 오늘 이미 게시한 수와 실제 할당량을 확인하기 전 숫자만 올려 강제 발행하지 않았다.
- `ANTHROPIC_API_KEY`는 비공개 GitHub Actions Secret 등으로 제공하고 값은 채팅에 넣지 않는다. 키만 추가했다고 미구현된 리서치·검수·게시가 자동으로 연결되지는 않는다.
- API를 연결할 때 최초 비공개 시험 상한1달러, 초기 하루 상한5달러를 집행할 비용 원장과 제한 검사가 필요하다. 현재 구현 완료로 표시하지 않는다.

## 검증 및 게시 결과

회차 경계·지연 허용·중복 회차·한국/UTC 변환·종료/다음날 차단·할당량 유지 테스트를 추가했다. 실제 새 카드 생성·예약·게시를 수행한 변경은 아니다. 회차별 원격 실행·게시 결과는 이후 실제 실행 기록에서 확인해야 한다.
