## 제품에 반영한 것

1. 밋밋한 단색 카드 대신 주제별 색·그래픽·종이 질감·큰 제목·진행 표시로 시리즈를 식별한다.
2. 표지 → 확인된 기사 → 독자 관점의 질문 → 저장용 체크리스트 → 독자의 선택 순으로 5장을 만든다.
3. 기사 사실과 편집 질문을 구분한다. 제공되지 않은 수치·지원 조건·개인에게 미칠 영향을 지어내지 않는다.
4. 연애·생활비·주말·생활 도구 범위에서 먼저 실험한다. 정치·참사 등의 포털 상위 노출을 이유로 무작정 계정에 섞지 않는다. 이 주제가 인스타 전체 1위라는 의미는 아니다.
5. 초안 생성과 실제 게시의 속도를 분리한다. 5분 수집·새 초안 생성 설정, 별도의 게시 한도와 최소 간격, 실제 인스타 근거가 있어야 게시한다.
6. 디자인 버전을 기록한다. 이미 만든 구버전 초안은 보존하고 새 디자인으로 다시 만들 수 있다. 이미 게시한 사건을 새 디자인이라는 이유로 재게시하지 않는다.

## 우리의 차별화 가설: 뉴스를 ‘내 선택’으로 바꾸는 사용설명서

계정 이름을 살려 독자가 자신과 가까운 사람의 기준을 확인하게 하는 시리즈를 만든다. 예를 들어 결혼·동거 뉴스라면, 기사에서 확인된 사실을 소개한 뒤 “생활비는 같은 금액인가, 소득 비율인가?”처럼 다음 대화의 출발점을 준다. 그 질문에 대한 정답이나 기사 속 인물의 의도를 지어내지는 않는다.

초기판은 주제별 공통 질문으로 구현했다. 매 기사에 맞춘 깊은 해설·직접 조사·독자의 실제 댓글 반영은 다음 단계다. 템플릿의 반복만으로 장기 경쟁력을 만들었다고 보지 않는다.

차별화 실험 후보:

- **우리 기준 카드:** 같은 뉴스를 보고 각자 어떤 기준을 갖는지 대화하는 저장용 카드.
- **한 달 뒤 확인:** 발표 뉴스의 시행 여부를 재확인하는 후속편. 원문 재검증과 사건 연결 기능은 아직 구현하지 않음.
- **독자의 말이 다음 편:** 실제 댓글에서 반복 질문을 뽑아 다음 편의 주제로 삼기. 실사용 댓글 수집 어댑터 연결 전에는 실행했다고 표시하지 않음.

## 돈이 들어오는 경로

우선 가설은 **관계·생활 콘텐츠 → 신뢰와 반복 방문 → 관련 브랜드 협업 + 자체 대화·생활 도구**다. 여행·맛집은 생활 동선에 맞을 때만 다룬다. 조회수가 높다는 이유로 모든 카테고리를 무작정 섞거나 협찬이 없는데 광고 수입이 생겼다고 표시하지 않는다.

매체 초기에는 적합한 독자와 수요를 확인한다. 자체 무료 대화 도구와 판매 상품이 준비되면 프로필 링크에 연결해 유입과 결제를 추적한다. 현재 연결된 상품·제휴 계약·무료 배포 페이지·매출 추적은 없다. 따라서 카드에 가짜 다운로드 링크나 수익 약속을 넣지 않았다. 협찬·제휴가 생기면 해당 콘텐츠의 경제적 이해관계를 명확하게 표시하도록 별도 경로를 만든다.

평가 지표는 좋아요만이 아니다. 도달 대비 저장·공유, 프로필 방문, 링크 클릭, 신청·구매, 환불 차감 후 매출과 제작·운영비를 본다. 데이터가 연결되기 전 값은 0이나 예상 매출로 채우지 않는다. 초기 2주 실험 기간도 일정 가설일 뿐 성공 보장이나 최소 표본 기준이 아니다. 비교할 때 게시 후 같은 경과 시간·주제·독자 규모를 맞추고, 차이를 곧바로 인과 효과로 단정하지 않는다.

## 5분 주기의 범위와 시크릿

GitHub Actions의 공식 최소 예약 간격은 5분이다. 현재 워크플로는 `2/5 * * * *`로 설정해 매시 02·07·12…57분 실행을 목표로 한다. 큐 지연·누락 가능성이 있어 정확히 매 5분 실행 또는 게시를 보장하지 않는다. 공개 저장소의 표준 Linux 실행기를 사용하며 별도 유료 서버나 유료 AI 호출을 추가하지 않았다.

- [GitHub schedule 공식 문서](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#onschedule)
- [예약 실행 지연 관련 공식 문서](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

인증값은 소유자가 GitHub Repository Secret `AUTOPILOT_CONFIG`에 입력해야 한다. ChatGPT에 연결한 앱의 토큰을 GitHub 실행기에 자동 복사할 수 없다. 키를 채팅에 보내거나 공개 파일에 저장하지 않는다. 구체적인 설정 형식은 README에 있다. 인증만 입력해도 실제 인스타 인기 근거 수집이 저절로 완성되는 것은 아니다. 해당 어댑터와 실제 운영 게시 상한 연결이 남아 있다.
