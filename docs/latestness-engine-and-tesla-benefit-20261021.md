# 브레이크 브리핑: 갱신 엔진·테슬라 독자 효용 · 2026-10-21

## 실제 구현

src/freshness.mjs가 등록된 원자료·업데이트 목록을 네트워크로 재조회한다. HTTP 캐시 재사용을 요청하지 않고, 확인 가능한 최신 문서의 내용 해시·수정 시각·후속 링크를 비교한다. 원문 전문은 상태 파일에 저장하지 않는다.
현재 원자료 등록: Tesla IR·SEC 목록/10월19일 위임장/한국 커넥티비티, 관세청 보도자료 목록·10월21일 수출 발표, 금융위 청년미래적금 및10월 시행 정책.
관세청 목록의 data-id/data-url을 관찰한 공식 상세보기 경로로 해석한다. 페이지 자바스크립트를 실행하지 않는다.
다음 기사 URL은 최근30일·최대60개 관측 이력을 보관해 메인에서 사라진 어제 기사도 확인한다. 이 경로는 공개 head 메타데이터만 비교한다. 본문에만 생긴 정정까지 모두 감지한다는 뜻이 아니다.
등록한 발표 목록의 새 링크 또는 원자료 변화·확인 실패가 있으면 해당 초안의 승인·검증을 무효화하고 재조사 큐에 넣는다. 게시된 원본은 보존하고 정정 검토 플래그를 남긴다. 외부 예약이 있으면 취소 필요 상태를 표시한다. 외부 취소 어댑터는 미연결이며 예약 취소 완료로 보고하지 않는다.
발행 직전에는 렌더에 쓴 자료 버전과 원자료를 두 번(검증 전·게시 직전) 대조한다. 렌더 자료의 검토 시각5분 초과, 자료 변경, 읽기 실패, 후속 목록 누락은 차단한다. 이후 실제 계정 할당량·마감 시각·독립 검증도 다시 검사한다.

## 범위와 한계

등록하지 않은 전 세계 모든 후속 기사까지 검색하는 엔진은 아니다. 신규 사건은 적절한 원자료·후속 목록을 등록해야 발행 전 관문을 통과할 수 있다. 메타데이터·HTML 공개 링크가 없는 동적 목록은 확인 실패로 처리하며 구조화 API 어댑터가 필요하다. 읽는 데 성공했어도 내용의 의미·정정 여부는 독립 검증이 필요하다.
변경 감지→기존 원고 무효화→재조사 대기까지 구현·실행기에 연결했다. 변경 내용을 자동 심층 조사해 새 카드로 재작성하는 AI 어댑터와 독립 내용 검증기·게시 인증은 여전히 미연결이다. 따라서 무인 자동 최신 카드 재발행의 완성이나 시작을 선언하지 않는다.
현재44개 테스트 통과. 어제 기사 수정, 메인 이탈 후 재조회, 후속 링크 추가, 재조회 실패, 검증 이후 수정, 외부 예약 무효화 표기, 기존 게시물 보존, stale cache 차단을 포함한다.
