# 생활경제·리빙 뉴스 — 추후 검토안

상태: **보관 / 시행 보류**. 2026-10-21 사용자가 현재 작업에 적용하지 말고 저장만 하도록 지시했다. 이 문서는 편집 헌법·주제 범위·자동발행 설정을 변경하지 않는다. 기존 엔진 저장·브랜드 로고·Claude API 연결 검토·지정 회차 자동발행 작업을 먼저 진행한다.

## 사용자의 구상

한국과 전 세계의 생활 관련 뉴스를 취합해 삶과 지출에 영향이 큰 소식을 선별한다. 리빙뿐 아니라 생활경제·정부 정책을 포함한다. 주부 및 20·30·40대 여성 독자에게 기존 엔진의 심층 조사·최신성·검증·시각화 원칙을 적용한 카드뉴스를 제공한다. 즉각적이고 선별된 정보를 분석해 독자가 실제로 활용할 수 있게 하고 수익화 방법을 찾는다.

## 재검토할 편집·사업 가설

- 포지셔닝 후보: 브레이크 브리핑 — 내 생활에 영향 있는 뉴스만, 이유부터 지금 할 일까지 1분에.
- 해외 변화 → 한국 적용 여부 → 대상 독자 → 실제 금액·조건 → 지금 할 행동까지 검증한다. 단순 번역·해외 혜택의 국내 적용 오인을 피한다.
- 집·장보기·주방·청소·생활가전·주거비·생활비·확정 정책을 후보로 삼되, 구매를 말리는 정보와 리콜·환불 정보도 제공한다.
- 가격 인상 예고나 정책 발표의 실제 후속 결과를 추적한다. 모든 게시물에 상품을 억지로 연결하지 않는다.
- 수익화 가설: 구매 판단 콘텐츠의 제휴 전환 측정 → 실제 전환을 근거로 협찬 검토 → 반복 수요가 확인된 맞춤 가격·혜택 알림 검토. 광고 관계는 명확히 표시한다.
- 첫 독자 가설은 집과 생활비 지출을 직접 결정하는 30~40대 여성. 검증 전 확정 타깃·시장 수요로 취급하지 않는다.
- 조회수뿐 아니라 저장·공유·정보 페이지 방문·신청/구매 전환·게시물당 순수익을 본다. 빠른 수익화는 보장되지 않는다.
- 30분마다 정보 확인과 30분마다 무조건 게시를 구분한다. 향후 이 방향을 승인받아도 검증·효용이 없는 회차는 채우지 않는다.
