## 주요 수익 경로 전체 지도
1. 협찬 게시물·스폰서 시리즈: 주제 맞는 광고주가 제작/게시비를 지불. 실측 도달·저장·클릭을 보고한다.
2. 콘텐츠 제작 대행·브랜드용 UGC: 팔로워가 적어도 결과물 제작에 대가를 받을 수 있는 별도 상품. 브랜드가 자체 채널에 게시한다. 우리 계정 도달을 보장하지 않는다.
3. 파트너십 광고 사용권: 광고주가 비용을 부담해 콘텐츠를 광고로 집행. 사용 기간·매체·편집 범위는 별도 합의. 광고비를 우리가 먼저 내지 않는다.
4. 제휴 링크·CPA/CPS: 공식 프로그램 승인·추적 링크·고지 필요. 현재 가입·상품·링크 미연결. 존재하지 않는 링크나 수익을 표시하지 않는다.
5. 공동구매·판매 수수료: 공급·배송·환불·고객 응대 역량 필요. 초기 뉴스 계정 우선순위에서 제외.
6. 자체 체크리스트·리포트·템플릿 판매: 직접 만든 독자 문제 해결 상품. 결제·상품 준비 전 CTA를 만들지 않는다. 내연사와 분리.
7. 유료 구독·기업 브리핑: 꾸준한 전문 정보·데이터를 제공한 뒤 검증. 초기에는 무료 뉴스레터 원고부터 축적.
8. 뉴스레터·사이트 광고: 인스타 유입 → 명시적으로 동의한 구독자 → 스폰서. 현재는 원고 묶음만 생성, 구독 폼·메일 발송은 미연결.
9. 기업 조사·설문·리드 상품: 명확한 동의와 목적 제한을 갖춘 향후 상품. 팔로워나 개인 연락처를 파는 사업이 아니다.
10. 플랫폼 구독·선물·보너스: 지역·계정·형식별 자격 확인 필요. 카드 조회수만으로 자동 수익이 난다고 계산하지 않는다. https://about.fb.com/ko/news/2023/12/instagram-gift-subscription-bonus-program/

## 초기 우선순위와 우리만의 가설
첫 매출은 제작 상품으로 시도 → 독자 반응이 쌓이면 분야별 스폰서 → 동의 구독자가 모이면 다채널 패키지. 제안 상품은 5장 제작 / 스폰서 시리즈 / 뉴스레터 패키지로 구분한다. 금액과 납기는 계약 전 확정하며 시장 단가나 예상 매출을 만들어내지 않는다.

독자 약속: ‘내 돈·내 시간·내가 해야 할 일’을 한 편에서 확인할 수 있는 실용 미디어. 현 버전은 질문·체크리스트 중심이며 사실 추출·조건 검증을 완성한 분석 기사로 부르지 않는다.
우리의 추가 아이디어: 같은 조건이 바뀌면 후속편으로 연결하는 결정 추적 시리즈 + 저장한 독자가 원자료를 확인하는 경로 + 게시물별 UTM + 7일 성과표. 현재 UTM 생성·실험 정의·뉴스레터 원고 묶음 구현, 웹 클릭 계측·원자료 변경 감지·자동 이메일은 미구현.

## 업로드 상태 구분
