- 이 둘은 국내 인스타 카드뉴스 계정의 조기 수익 실증 사례가 아니다. 구조를 참고한 가설이다.

## 우리의 실험
‘소식 → 나에게 해당하는 조건 → 공식 확인 → 행동 체크리스트’ 5장.
혜택·생활비·업무 도구·주말 정보 순으로 제목 기반 편성 가설을 적용한다. AI라는 단어가 들어간 기업 실적·사건 사고를 수익형 도구 소개로 분류하지 않는다. 포털 노출 순위는 인스타 인기 순위가 아니다.

차별화 가설: 동일 이슈의 신청 마감·시행일·가격 조건이 바뀌면 후속편으로 업데이트하는 ‘조건 추적’ 시리즈. 현재 버전은 최초 체크리스트 제작까지만 구현했고, 원자료 조건 추출·후속 변경 감지는 미구현이다. 숫자·기한·대상을 제목만 보고 만들어내지 않는다.

초기 수익 제안: 주제별 스폰서 1회 시험 판매 → 성과 보고 → 반복 계약. 가격은 실제 도달·링크 클릭·광고주 전환 결과로 협의한다. 광고주가 없는 단계에서 가짜 광고·제휴 링크·판매 중인 상품을 표시하지 않는다. 외부 영업은 별도 사용자 지시 없이 보내지 않는다.
측정: 게시물별 도달·저장·공유·프로필 방문·실제 클릭·광고 문의·매출. 지금 매출/전환 연결은 미연결이며 점수는 예측 매출이 아니다.

## 운영 상태와 권리
- GitHub cron: 2/5 * * * *, 5분 목표. 플랫폼 지연/누락 가능. 새 적합 후보가 없으면 반복 제작하지 않는다.
- 다음 메인 뉴스 13건에서 제목 기반 우선순위로 회당 새 초안 1건(5장) 제작. 기사 본문·사진 복사 없음. 짧은 소개문 사용이 곧 이용 허락이라는 뜻도 아니다.
- 네이버 API는 별도 이용 범위 확인 전 비활성. 키는 삭제하거나 노출하지 않는다.
- 다음은 허가 우회 수단이 아니다. 미확인 포털 초안은 내부 검토용이며 자동 SNS 발행 자격이 없다. 현재 공개 GitHub data 브랜치에 저장되는 초안은 비공개 자료가 아니므로 민감 자료를 넣지 않는다.
- 기사별 상업적 이용·가공·SNS 게시·자동처리 허가와 근거 URL을 확인한 자료만 실제 게시 심사 통과. 도메인 전체를 허가된 것으로 간주하지 않는다.
- 공식 발표/공공누리 1유형 등 허용 원자료 수집기는 아직 연결되지 않았다. 개별 자료 조건·사진 예외를 확인해 추가해야 한다.
- 인스타 인증·일일 운영 한도·실측 인스타 근거 연결 전 자동 업로드는 대기한다.
